# Harsh Dagar - Full Stack Developer Portfolio

A modern, responsive, and performance-optimized personal portfolio website built with **React**, **Tailwind CSS**, and **Framer Motion / Motion**.

## 🚀 Live Demo
- **Portfolio:** [harshdagar.vercel.app](https://github.com/harshdagar0/Portfolio)
- **LinkedIn:** [harsh-dagar](https://www.linkedin.com/in/harsh-dagar-716125256/)

---

## 🛠️ Tech Stack

- **Framework:** React 18 (Vite)
- **Styling:** Tailwind CSS, PostCSS
- **Animations:** Motion / Framer Motion
- **Icons:** React Icons (Simple Icons, FontAwesome, Feather Icons)
- **Forms:** Formspree (`@formspree/react`)
- **Deployment:** Vercel

---

## ✨ Features

- **Responsive Design:** Seamless experience across mobile, tablet, and ultra-wide screens.
- **Glassmorphic Navigation:** Sticky header with quick anchor links and a mobile dropdown menu.
- **Interactive Projects Showcase:** Links to live deployments and GitHub repositories.
- **Technical Skills Categorization:** Visual icons for languages, frontend, backend, databases, and DevOps tools.
- **Professional Experience Timeline:** Structured career highlights with tech badges.
- **Working Contact Form:** Integrated with Formspree for direct email notifications.
- **SEO & Social Cards:** Comprehensive Open Graph (OG) meta tags and Twitter preview cards.

## 💻 Local Development

Clone the repository and install dependencies:

```bash
git clone https://github.com/harshdagar0/Portfolio.git
cd Portfolio
npm install
```

Start the local development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
